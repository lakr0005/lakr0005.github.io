5 html tag i learned

<h1> to <h6>
These tags are used for headings, with <h1> being the most important and <h6> the least important.
<p>
This tag is used for paragraphs.
<ul>
This tag is used for unordered lists.
<ol>
This tag is used for ordered lists.
<img>
This tag is used to embed images in a webpage.
